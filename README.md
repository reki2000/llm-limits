# llm-limits

Claude と Codex のサブスクリプション利用枠の残量を、リアルタイムに表示するデスクトップアプリ。

アカウントごとに **5時間枠と週間枠それぞれの消費率と、次回リセット日時** を表示する。

- ローカル常駐サーバが各サブスクアカウントに OAuth でログインし、残量を定期取得する
- 取得したクレデンシャルは端末内（OS キーチェーン）にのみ保存する
- 表示はまずサーバ提供の Web UI。各 OS のメニューバー常駐クライアントは後続フェーズ
