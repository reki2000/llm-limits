# llm-limits

Claude と Codex のサブスクリプション利用枠の残量を、リアルタイムに表示するデスクトップアプリ。

アカウントごとに **5時間枠と週間枠それぞれの消費率と、次回リセット日時** を表示する。

- ローカル常駐サーバが残量を取得し、Web UI に配信する
- Codex は公式の `codex app-server` (JSON-RPC) 経由で取得する
- Claude は公式 CLI が管理するクレデンシャルを使う
- **公式クライアントの OAuth client_id は流用しない**（詳細は設計書 §2）
- 各 OS のメニューバー常駐クライアントは後続フェーズ

公式 CLI (`codex` / `claude`) がインストール済みであることを前提とする。
